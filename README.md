# Flower Knows — Website Redesign Concept

โปรเจกต์ออกแบบและพัฒนาหน้าเว็บไซต์เครื่องสำอางสำหรับงานรายวิชา โดยใช้เว็บไซต์ **AOU Cosmetics** เป็นเว็บไซต์ต้นแบบ และนำผลิตภัณฑ์ ภาพสินค้า และเนื้อหาของ **Flower Knows** มาประยุกต์ใช้ พัฒนาด้วย HTML, SCSS/CSS และ JavaScript

## ที่มาและแนวคิด

โจทย์ของรายวิชาคือการนำผลิตภัณฑ์ในหมวดเดียวกันมาประยุกต์ในการออกแบบใหม่ โปรเจกต์นี้จึงเลือกผลิตภัณฑ์ในหมวดเครื่องสำอาง โดยศึกษาแนวทางการจัดวางองค์ประกอบและการนำเสนอสินค้าจาก [AOU Cosmetics](https://aoucosmetics.com/) แล้วปรับให้เข้ากับเนื้อหาของ Flower Knows

งานนี้เป็น **Website Redesign Concept / Frontend Practice** ที่เน้นการฝึกจัดวางหน้าเว็บ การนำเสนอภาพสินค้า และการสร้างปฏิสัมพันธ์ด้วย JavaScript โดยมีหน้าแรกเป็นขอบเขตหลัก

## ส่วนประกอบและการทำงาน

- แถบข้อความโปรโมชันแบบเลื่อนต่อเนื่อง และแถบนำทางที่เปลี่ยนรูปแบบเมื่อเลื่อนหน้า
- เมนูด้านข้างแบบเปิด–ปิด พร้อมหมวดหมู่ที่ขยายและยุบได้
- ช่องกรอกคำค้นหาพร้อมปุ่มล้างข้อความ
- แบนเนอร์สไลด์อัตโนมัติ พร้อมปุ่มเปลี่ยนสไลด์
- ส่วนแสดงสินค้า Best Seller, New และ Ready-To-Gift
- ส่วน Collection ที่เชื่อมการเปลี่ยนภาพแบบ Polaroid กับรายการสินค้า
- ส่วน About ที่เปลี่ยนภาพตามเมนู และส่วนแสดงภาพ Social
- เคอร์เซอร์ตกแต่งและแอนิเมชันประกอบหน้าเว็บ
- การปรับรูปแบบการแสดงผลตามขนาดหน้าจอด้วย Bootstrap, media queries และการตั้งค่า Swiper

## เทคโนโลยีที่ใช้

| เทคโนโลยี | การใช้งาน |
| --- | --- |
| HTML5 | โครงสร้างและเนื้อหาหน้าเว็บ |
| SCSS / CSS3 | รูปแบบหน้าเว็บ การจัดวาง และแอนิเมชัน |
| JavaScript | การควบคุมเมนู สไลเดอร์ และปฏิสัมพันธ์ |
| Bootstrap 5 | ระบบจัดวางและ utility classes |
| Swiper | แบนเนอร์และสไลเดอร์สินค้า/ภาพ |
| Font Awesome | ไอคอน |
| Gulp + Sass + gulp-csso | คอมไพล์ SCSS และสร้าง CSS แบบย่อ |
| BrowserSync | เปิดเซิร์ฟเวอร์สำหรับพัฒนาและรีโหลดหน้าเว็บ |

## วิธีเปิดใช้งาน

### เปิดดูหน้าเว็บ

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรือใช้ Live Server ใน Visual Studio Code ได้โดยตรง เนื่องจากมีไฟล์ CSS ที่คอมไพล์แล้วอยู่ในโปรเจกต์

ควรเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดไลบรารีและฟอนต์ที่อ้างอิงผ่าน CDN

### พัฒนาต่อด้วย Gulp

ติดตั้ง Node.js และ npm จากนั้นเปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:

```bash
npm install
npm start
```

คำสั่ง `npm start` จะคอมไพล์ `assets/scss/main.scss` ไปยัง `css/main.css` และ `css/min/main.css` จากนั้นเปิด BrowserSync โดยแสดง URL ใน Terminal

Gulp จะติดตามการเปลี่ยนแปลงไฟล์ SCSS และ HTML ให้โดยอัตโนมัติ หากแก้ไข JavaScript ให้รีเฟรชเบราว์เซอร์ด้วยตนเอง

> **หมายเหตุเกี่ยวกับ build:** ปัจจุบัน `npm run build` เรียก `gulp scss` แต่ `gulpfile.js` ยังไม่ได้ export task ชื่อ `scss` จึงยังใช้คำสั่งนี้ไม่ได้ หากต้องการเปิดใช้คำสั่ง build ให้เพิ่ม `exports.scss = scssTask;` ใน `gulpfile.js` ก่อน

## โครงสร้างโปรเจกต์

```text
flowerknows-website-redesign/
├── index.html               # หน้าเว็บหลัก
├── script.js                # การทำงานของเมนูและสไลเดอร์
├── assets/
│   └── scss/
│       ├── main.scss        # สไตล์หลักสำหรับคอมไพล์
│       └── _variables.scss  # ตัวแปร SCSS ที่ main.scss ใช้
├── css/                     # ไฟล์ CSS รวมถึง main.css ที่หน้าเว็บโหลด
│   └── min/                 # ไฟล์ CSS แบบย่อ
├── font/                    # ไฟล์ฟอนต์ภายในโปรเจกต์
├── images/                  # ภาพและไอคอนที่ใช้ประกอบหน้าเว็บ
├── picture/                 # ไฟล์ภาพเพิ่มเติม
├── gulpfile.js              # การตั้งค่าคอมไพล์และเซิร์ฟเวอร์พัฒนา
├── package.json             # dependencies และคำสั่ง npm
└── package-lock.json        # รายละเอียดเวอร์ชัน dependencies
```

เมื่อต้องการแก้สไตล์หลัก ให้แก้ `assets/scss/main.scss` และ `assets/scss/_variables.scss` แล้วคอมไพล์ผ่าน Gulp

## ขอบเขตของงาน

โปรเจกต์นี้เป็นต้นแบบส่วนติดต่อผู้ใช้แบบหน้าเดียว ยังไม่มี Backend ฐานข้อมูล ระบบสมาชิก ตะกร้าสินค้า การชำระเงิน หรือระบบค้นหาสินค้าจริง ช่องค้นหาสาธิตการกรอกและล้างข้อความเท่านั้น

ลิงก์หลายส่วนยังเป็น `#` หรือ `https://example.com/product1` เพื่อใช้วางโครงสร้างหน้าเว็บ ข้อมูลสินค้า ราคา และโปรโมชันที่แสดงเป็นเนื้อหาประกอบงานออกแบบ
